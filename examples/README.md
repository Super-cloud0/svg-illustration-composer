# Примеры композиций

Сгенерированы `npm run examples` тем же кодом, что и веб-приложение.

### 01_metaphor_ucheba-i-koncentraciya
- Сценарий: метафора — «учёба и концентрация»
- Шаблон: title, формат 1200×630, размер L, палитра purple, декор none, масштаб 29%
- book: «учеба» → тема «учёба»
- lamp: «учеба» → тема «учёба»; «концентрация» → тема «концентрация»
- headphones: «концентрация» → тема «концентрация»
- pen: «учеба» → тема «учёба»

![01_metaphor_ucheba-i-koncentraciya](01_metaphor_ucheba-i-koncentraciya.png)

### 02_metaphor_finansovaya-gramotnost
- Сценарий: метафора — «финансовая грамотность»
- Шаблон: collected, формат 1200×1200, размер L, палитра peach, декор waves, масштаб 66%
- book (фон): «грамотность» → тема «знания»; крупный второстепенный объект — фоновым вариантом, чтобы не перекрывать главные
- wallet: «финансовая» → тема «деньги»
- coin: «финансовая» → тема «деньги»

![02_metaphor_finansovaya-gramotnost](02_metaphor_finansovaya-gramotnost.png)

### 03_components_phone-headphones-bg-flowers
- Сценарий: компоненты — «телефон, наушники, фоновые цветы»
- Шаблон: offset, формат 1080×1350, размер S, палитра teal, декор confetti, масштаб 63%
- phone: указан компонент «телефон»
- headphones: указан компонент «наушники»
- flowers (фон): указан компонент «фоновые цветы» (фоновый вариант)
